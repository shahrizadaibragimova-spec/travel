# 🌸 Wanderlust — World Flight Explorer

## Запуск (Windows, VS Code):

1. Открой папку `flight_explorer3` в VS Code
2. Открой терминал
3. Запусти:

```
pip install django
python manage.py runserver
```

4. Открой в браузере: http://127.0.0.1:8000/

## Что есть на сайте:
- 🌸 Пастельный эстетик дизайн
- 📸 Фото каждой страны на карточке
- 🏙 При клике — 3 лучших города + что там делать
- 🔤 3 языка: English / Русский / Кыргызча
- 🔍 Поиск + фильтр по континентам
- ✈ Поиск рейсов через Google Flights
- 🌸 Анимированные лепестки цветов
